## Cara menjalankan

1. Pasang GDevelop 5.
2. Buka `game/game.json` (ekstrak seluruh folder `game/` lebih dulu, jangan hanya file json).
3. Klik Preview untuk mencoba.
4. Ekspor web: Project, Export, Web (HTML5), lalu unggah isi folder hasil ekspor ke webhost lab.

## Kontrol

A/D atau panah = gerak, Spasi/W = lompat, Q = Turbo, E = Perisai, T = Toko (dari menu atau jeda), ESC/P = jeda, R = ulang level, M = suara.
